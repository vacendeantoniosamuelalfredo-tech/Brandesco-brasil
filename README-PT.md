# Etau Pix Signature

Front-end independente para prototipagem.

## Acesso de demonstração
- E-mail: `samuel@etaupix.test`
- Palavra-passe: `EtauTeste25`
- Código de teste 2FA: `00005`

Os valores são ilustrativos. O login e o código ficam no JavaScript do navegador e NÃO são segurança real; qualquer pessoa pode inspecionar o código. Operações PIX ficam bloqueadas até integração com um backend e prestador autorizado. Não use credenciais bancárias reais.

## Publicar
Extraia o ZIP, carregue `index.html` e `mulher-fundo.jpg` para a raiz de um repositório e ative GitHub Pages.
